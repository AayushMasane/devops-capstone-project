# User Stories

## Customer Accounts Microservice

- As a customer, I want to create an account so that I can access personalized services.
- As a customer, I want to log in securely so that my data remains protected.
- As a customer, I want to update my profile details so that my information is up to date.
- As a customer, I want to reset my password so that I can regain access if I forget it.
- As a customer, I want to view my account history so that I can track past activities.
- As a customer, I want to delete my account so that my data can be completely removed.
- As an administrator, I want to manage customer accounts so that I can support platform operations.
